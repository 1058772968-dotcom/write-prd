# write-prd · 根据交互原型写 PRD

一个面向 Codex 的中文产品需求文档 Skill。把交互原型、产品想法、已有 PRD 和评审材料整理成结构清晰、可评审、可继续编辑的 PRD，让设计、研发和业务人员看懂需要做什么、如何操作，以及做到什么算完成。

适用于网站、App、硬件配套软件、AI 功能及内部工具。既可以从原型新建文档，也可以根据评审意见修订已有 PRD。

## 它能帮你做什么

- **从原型梳理功能**：整理模块、入口、控件、默认状态、用户操作和可观察结果。
- **明确功能规则**：逐项说明字段限制、前置条件、权限、状态保持及注意事项，缺失信息标为“待确认”。
- **组织版本范围**：给出核心流程和功能全景矩阵，区分本期范围、后续建议与未确定安排。
- **对应原型与需求**：在功能表格最后一列放置原型图或明确图位，与每行子功能对应。
- **补齐交互流程**：用可编辑文本表达正常路径、条件分支、状态变化及数据流转。
- **形成验收要求**：按输入、操作和可观察结果定义完成标准，并梳理适用的异常场景。

原型中出现界面，不代表相应服务已经实现；模板示例也不会自动成为产品需求。

## 安装

### 通过 Codex 的 skill-installer 安装

在已提供 `$skill-installer` 的 Codex 环境中发送：

```text
请使用 $skill-installer，从 GitHub 仓库
https://github.com/1058772968-dotcom/write-prd
安装技能。技能在仓库根目录，路径为 .，安装名称为 write-prd。
```

### 手动安装

已安装 Git 时，可在 macOS / Linux 终端执行：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
git clone https://github.com/1058772968-dotcom/write-prd.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/write-prd"
```

也可以下载仓库 ZIP，解压后将包含 `SKILL.md` 的文件夹命名为 `write-prd`，放入 Codex 的个人技能目录。默认位置为 `~/.codex/skills`；设置了 `CODEX_HOME` 时使用其下的 `skills` 目录。

已有同名技能时，先比较内容并保留自己的修改。安装后在下一轮对话中调用 `$write-prd`。

## 使用示例

先提供原型截图、原型文件或可访问的原型链接，再发送：

```text
请使用 $write-prd，根据我提供的交互原型编写中文 PRD。
逐页梳理功能、控件、默认状态和交互结果，补充限制条件、
交互流程、验收要求和特殊情况。
原型无法确定的规则请标为“待确认”，不要自行编造。
```

修订已有文档：

```text
请使用 $write-prd，根据这次评审意见修改现有 PRD。
保留已确认的产品定位与版本范围，只调整相关章节，
并集中列出仍需确认的事项。
```

希望实际插入原型图片时，可以进一步说明：

```text
请把我提供的原型截图插入对应功能行的“原型展示”列，
标清页面、弹窗或关键状态；同一张图覆盖多行时用编号引用。
```

## 默认文档结构

| 章节 | 主要内容 |
| --- | --- |
| 第 1 章 · 要做什么 | 产品定位、核心流程、功能全景矩阵、本期不做 |
| 第 2 章 · 具体功能要求 | 模块目的与入口、功能规则、原型展示、交互与数据流转 |
| 第 3 章 · 通用交互要求 | 跨模块共用的交互要求 |
| 第 4 章 · 做到什么算完成 | 可观察、可验证的验收要求 |
| 第 5 章 · 开发前需确认的信息 | 尚未明确的规则、资源、输入及版本安排 |
| 第 6 章 · 特殊情况说明 | 边界、重复、中断、网络异常、权限与资料保护等适用场景 |

具体功能默认使用五列表格：

| 子功能 / 控件 | 展示与默认状态 | 操作及结果 | 限制条件与注意事项 | 原型展示 |
| --- | --- | --- | --- | --- |
| 按实际原型填写 | 位置、文案、默认状态 | 用户动作及结果 | 有依据的规则；未知项待确认 | 对应图片或明确图位 |

完整模板见 [assets/prd-template.md](assets/prd-template.md)，流程写法见 [references/flow-patterns.md](references/flow-patterns.md)。用户当前指定的结构、范围与格式优先于默认模板。

## 使用边界

- 默认交付可编辑 Markdown；Word、PDF 或在线文档需要运行环境提供相应能力。
- 读取在线原型、浏览交互页面或解析特定文件，依赖当前环境的访问权限和工具；本仓库不包含浏览器、Figma 或文档导出程序。
- 默认保留用户认可的图片或设置明确图位，不自动截图或生成原型图片；实际插图需明确提出。
- 功能矩阵中的 ✅ 表示纳入版本范围，不代表已经开发或验收；未确认的后续版本标为建议或待规划。
- 写 PRD 本身不会自动同步在线文档、建业务表、运行产品服务或执行文档中描述的功能。
